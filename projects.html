Fantasy Football Lineup Optimizer

Connects to my ESPN Fantasy Football league via the ESPN Fantasy API to pull my roster, free agents, and injury statuses fresh on every page load via a Cloudflare Pages Function. Combines that with real historical defense-vs-position performance data (nflverse) to build an opponent-adjusted scoring model. The model ranks every player on my roster and every available free agent at each position, then recommends the starting lineup and any free-agent swaps that maximize my expected points for that week's matchup. Automated Deficiency Report Tracker

A tool for my company's administrative workflow: platoon leaders and section leaders file written reports on negative incidents, and this project would parse those reports, extract the individuals named, match each name to the correct roster ID, and log the entry directly into the company's negative deficiencies tracker. Aims to cut down on manual data entry and reduce transcription errors between the report and the tracker.
