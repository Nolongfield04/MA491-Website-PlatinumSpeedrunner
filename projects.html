Fantasy Football Lineup Optimizer

Connects to my ESPN Fantasy Football league via the ESPN Fantasy API to pull my roster, matchups, and league settings each week. Combines that with statistics scraped from public sources (weekly projections, opponent defensive rankings, injury reports, snap counts) to build an opponent-adjusted scoring model. The model ranks every player on my roster and every available free agent at each position, then recommends the starting lineup and any free-agent swaps that maximize my expected win probability for that week's matchup.

Automated Deficiency Report Tracker

A tool for my company's administrative workflow: platoon leaders and section leaders file written reports on negative incidents, and this project would parse those reports, extract the individuals named, match each name to the correct roster ID, and log the entry directly into the company's negative deficiencies tracker. Aims to cut down on manual data entry and reduce transcription errors between the report and the tracker.
