# platinumspeedrunner.dev

Personal website — About, Resume, and Math Projects pages.
Plain HTML/CSS/JS, no build step. Deployed via Netlify from this GitHub repo.

## Structure

- `index.html` — About page
- `resume.html` — Resume / accomplishments
- `projects.html` — Math projects
- `style.css` — shared styles

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static
file server.

## Deploy

Pushes to `main` auto-deploy on Netlify (once the site is linked to this repo).
